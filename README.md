# Sistema de Gestão de Oficina

Projeto desenvolvido para a disciplina de **Tópicos Avançados de Engenharia de Software**, com o objetivo de aplicar, de forma evolutiva, conceitos de Engenharia de Software no desenvolvimento de um sistema de gestão para oficinas mecânicas.

## Sobre o Projeto

O sistema é voltado para o **uso interno da oficina**, permitindo o gerenciamento de:

- Clientes
- Veículos
- Ordens de serviço
- Serviços
- Peças e estoque
- Orçamentos e pagamentos

Durante a disciplina, o projeto será continuamente **refatorado, expandido e evoluído**, incorporando conceitos de Engenharia de Software e evoluindo sua arquitetura até uma abordagem baseada em **microsserviços**.

## Objetivo

Centralizar e facilitar os processos internos de uma oficina mecânica, proporcionando maior organização, controle e acompanhamento das atividades.

## Tecnologias

As tecnologias utilizadas serão definidas e evoluídas ao longo do desenvolvimento do projeto.
